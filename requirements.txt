# Consolidated Python dependencies for the whole repo (hil nodes, HIL_realtime_rendering,
# HIL_modular_autonomy, PIDNet/SparseInst). Replaces the old Docker-era requirements and the
# per-package requirements in src/hil/src/HIL_modular_autonomy and src/hil/src/HIL_realtime_rendering.
#
# Target: Python 3.12 (Ubuntu 24.04 / ROS 2 Jazzy) in a virtualenv, e.g.
#   python3 -m venv --system-site-packages ~/venvs/hil && source ~/venvs/hil/bin/activate
#   (--system-site-packages so the venv can see ROS packages: rclpy, cv_bridge, message_filters, ...)
#   pip install -r requirements.txt
#
# NOT installable with pip (come from ROS / system):
#   rospy, rclpy, cv_bridge, message_filters, tf, rospkg, ros_numpy, sensor_msgs, geometry_msgs,
#   septentrio_gnss_driver, pacmod2_msgs  (ROS packages)
#   Blender's `bpy` is only needed to author new assets (models/blender), not to run anything here.
#
# Install separately, in this order, BEFORE the rest if you need a specific CUDA build:
#   1. torch + torchvision matching the car's CUDA (https://pytorch.org/get-started/locally/).
#      The dev machine uses torch 2.4.1+cu121 / torchvision 0.19.1+cu121.
#   2. detectron2 (needed by SparseInst / HIL_modular_autonomy/agent.py):
#        pip install --no-build-isolation 'git+https://github.com/facebookresearch/detectron2.git'
#      (this also brings fvcore and pycocotools)
